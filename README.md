# Rutuja Janbandhu — Portfolio

Minimal premium portfolio built with React + Vite + CSS Modules. No Tailwind. No TypeScript.
Here it is -
- [rutuja-janbandhu](https://rutuja-janbandhu.netlify.app/)

## Install

```bash
npm install
npm run dev
```

Open http://localhost:5173

## Build

```bash
npm run build
npm run preview
```

## Resume

Place your PDF at `public/resume.pdf` so the **Download resume** links work on the site.

## Structure

```
src/
  components/
    Loader/       Navbar/    Hero/        About/
    Experience/   Skills/    Projects/    Achievements/
    Contact/      Footer/
  hooks/          useScrollReveal.js, useActiveSection.js
  data/           content.js
  styles/         globals.css, variables.css
  App.jsx  main.jsx
```
